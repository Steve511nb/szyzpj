# 宋致远的个人作品集网站

静态 3D 个人作品集，包含简历、影像作品和联系方式。

GitHub Pages 发布目录：`main` 分支根目录 `/`。

所有网页资源已包含在仓库内，无需安装依赖或运行构建。请通过 HTTP 服务预览，直接双击 HTML 文件可能无法加载 3D 模型。

此版本适合分批上传：整站约 60.4 MiB，单文件最大约 8.75 MiB。四个 AI 视频为 H.264、854 像素宽、24 帧，已降低码率；大 WebP 图片采用高质量有损压缩，保留原始分辨率。3D 模型、背景视频与 JPEG 图片保持原文件。页面样式及交互保持原样。

上传时将本目录中的内容放在仓库根目录，使 `index.html` 与 `.nojekyll` 位于根目录。GitHub Pages 选择 `Deploy from a branch`、`main`、`/(root)`。无需上传旧项目、原始视频或 `.git` 目录。

浏览器上传建议分批提交，每批约 10–15 MiB；四个 ai-web 视频分别单独上传。保持 assets/ 和 portfolio/assets/ 的原目录位置，避免把所有图片直接放进仓库根目录。不要将压缩包直接当作网页上传，GitHub Pages 不会自动解压。
